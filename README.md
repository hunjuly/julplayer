# JulPlayer

MKV, MOV, MP4, AVI 등을 지원하는 macOS용 동영상 플레이어입니다. Finder에서 영상을 열거나 플레이어에 끌어놓으면 해당 영상을 바로 재생하고 같은 폴더의 영상으로 재생목록을 갱신합니다. 재생이 끝나면 다음 파일로 넘어갑니다.

**파일 → 기본 플레이어로 연결 → 모든 동영상 형식 연결**을 선택하면 지원하는 확장자 전체를 한 번에 설정할 수 있습니다. 일부 형식은 macOS에서 확인을 요청할 수 있습니다.

## 빌드 및 실행

macOS 13 이상과 Xcode Command Line Tools가 필요합니다. 첫 빌드에서 재생 엔진인 libmpv와 자막 추출용 FFmpeg를 자동으로 내려받습니다.

```sh
git clone https://github.com/hunjuly/julplayer.git
cd julplayer
./build.sh
open ./JulPlayer.app
```

## 작품 정보와 AI 자막

제목 막대의 **ⓘ 작품 정보**, **파일 → 작품 정보** 또는 `I`로 소개를 열면 제목 바로 아래에 평점과 출처, 공개된 평가 인원이 표시됩니다. 그 아래에서 장르, 출시 연도, 분량, 제작사와 줄거리를 볼 수 있습니다. 일본 애니는 AniList에서 먼저 찾습니다. `카우보이 비밥/시즌 1/01.mkv`처럼 파일명이 회차뿐이면 폴더명으로 찾고, 후보가 여러 개면 직접 고를 수 있습니다. 영화는 영상 옆에 `영상파일명.md`로, 시리즈는 같은 시즌에서 함께 쓰는 `작품정보.md`로 저장합니다. 다음에 열면 직접 편집한 내용도 그대로 표시합니다.

**JulPlayer → OpenAI 설정** (`⌘,`)에 API 키를 등록하면 애니·영화·드라마의 상세 소개를 한국어로 읽을 수 있습니다. **볼 만한가?**에는 어떤 취향에 맞고 어디에서 호불호가 갈리는지, **작품성**에는 연출·각본 같은 요소가 감상에 어떤 영향을 주는지 담습니다. 확인한 비평은 출처를 함께 표시합니다. 결말을 짚어야 하는 해설은 맨 아래 **스포일러 주의**를 펼치면 보입니다.

예전에 저장한 문서는 **상세 소개 추가**, 외국어 원문은 **한국어 소개 추가**로 보강할 수 있습니다. 기존 소개와 메모도 파일에 남습니다. 같은 API 키로 일반 영화·시리즈 웹 검색, 음성 인식과 자막 번역을 사용할 수 있습니다. AniList 조회와 원문 자막 추출은 키 없이도 가능합니다.

같은 설정의 **자막 번역 모델**에서 **모델 목록**을 열어 고르거나 모델 ID를 직접 입력하세요. 저장한 모델은 대기열에서 다음으로 시작하는 영상부터 사용하며 앱을 다시 열어도 유지됩니다. 입력란을 비우고 저장하면 기본 모델인 `gpt-6.2-sol`로 돌아갑니다.

제어판의 자막 메뉴나 **재생 → AI 자막 생성**을 누르면 플레이어 오른쪽에 자막 패널이 열립니다. **현재 영상 추가**로 한 편을, **여러 편 선택**으로 재생목록의 여러 편을 담습니다. 대기열은 추가한 순서로 한 편씩 처리하며, 패널을 닫거나 다른 영상을 재생해도 계속됩니다. **대기열**에서 진행률과 저장 파일을 확인하거나 개별 작업을 취소할 수 있습니다. 대기 중인 작업은 앱을 종료할 때 정리됩니다.

영어로 표시된 음성 트랙에서 일본어가 들리면 **원본 언어 → 일본어**를 고르세요. **원문 + 한국어**는 영상 옆에 `영상파일명.ja.srt`를 먼저 저장한 뒤, 번호와 시간이 들어 있는 한 편의 원문 SRT 전체를 선택한 모델에 보내 한 번에 번역합니다. 모델이 실제 출력 한도에 도달하면 같은 원문 전체를 보면서 남은 번역을 이어 받습니다. 원본 번호를 모두 확인한 뒤 같은 타임코드의 `영상파일명.ko.srt`를 저장합니다.

**원문만**을 고르면 일본어 SRT만 만들 수 있습니다. 기존 파일은 보존하며, 내용이 같은 원문은 다시 사용합니다. 같은 영상을 재생 중이면 자막 목록에 두 파일이 추가되고 한국어가 표시됩니다.

텍스트 자막은 원래 타임코드를 유지하고, 음성은 대사 구간에서 시간을 추정합니다. OpenAI에는 번역할 대사나 선택한 음성 구간을 보냅니다. 여러 편을 담으면 각 영상에서 같은 순번의 내장 트랙이나 같은 이름 규칙의 외부 자막을 사용합니다.

## 주요 조작

같은 폴더에 영상 이름과 일치하는 외부 자막이 있으면 그 자막을 기본으로 표시합니다. 자막 목록에서 내장 자막으로 바꿀 수 있고, 자막을 끄면 다음 영상에서도 꺼진 상태가 유지됩니다. 오디오와 자막은 직전에 사용한 트랙 순번을 기억하며 해당 순번이 없으면 1번으로 돌아갑니다.

영상이 열려 있으면 왼쪽 위 노란 버튼이나 `P`로 화면 속 화면(PiP)을 시작할 수 있습니다. PiP에서 10초 앞으로 넘겨 끝에 닿으면 다음 영상이 이어집니다. 창만 최소화하려면 `⌘M`을 누르세요. 영상이 없을 때는 노란 버튼도 창을 최소화합니다.

재생 중인 창은 항상 위에 표시되고, 일시 정지하면 다른 창으로 가릴 수 있습니다. 제목 막대 오른쪽에는 재생목록, 작품 정보, 삭제 버튼이 있습니다. 재생목록은 영상 위에 잠깐 열리며, 항목을 고르거나 목록 밖을 클릭하면 닫힙니다. 삭제 버튼을 누르면 영상과 함께 지울 자막을 확인할 수 있습니다.

하단 제어판에서 재생·일시 정지와 이전·다음 파일을 조작합니다. 재생 버튼 바로 옆의 반원 화살표를 누르면 10초, 그 바깥의 원형 화살표를 누르면 60초 앞뒤로 이동합니다. 버튼에 마우스를 올리면 이동 시간과 단축키가 표시됩니다. 공간이 부족하면 양쪽 60초 버튼부터 숨기고, 최소 폭에서는 재생 버튼만 표시합니다. 창 안에서 마우스를 움직이면 제어판과 제목 막대가 나타나고, 영상 위에서 2초간 움직이지 않으면 다시 숨습니다. 전체화면에서는 커서도 함께 숨습니다.

창을 넓히면 진행바가 한 줄 제어판의 가운데에 놓이고, 두 줄일 때는 윗줄을 채웁니다. 진행바 왼쪽에는 현재 재생 시간, 오른쪽에는 전체 길이가 표시됩니다. 전체 길이가 1시간 이상이면 `1:23:45` 형식으로 표시합니다.

10초나 60초 앞뒤로 이동하면 화면 왼쪽 위에 현재 시간과 전체 길이가 `12:34 / 1:23:45`처럼 잠깐 표시됩니다. 음량이나 재생 상태를 단축키로 바꿔도 같은 자리에 표시됩니다.

파일이 바뀌면 현재 창의 가로폭을 유지하고 새 영상 비율에 맞춰 높이를 조절합니다.

HDR10·HLG 영상은 HDR이 활성화된 화면에서 HDR로 재생하고, 일반 화면에서는 밝기와 색을 SDR에 맞춰 자동으로 톤 매핑합니다. 창이나 PiP를 다른 화면으로 옮기면 해당 화면에 맞춰 전환합니다.

HDR 영상에서는 하단의 해 아이콘 옆에 현재 밝기 배율이 표시됩니다. **☀︎ ×1**을 누르면 슬라이더로 **×1**부터 **×10**까지 한 단계씩 조절할 수 있습니다. **재생 → 영상 밝기**에서도 같은 슬라이더를 열 수 있습니다. 기본값은 ×1이며, 선택한 밝기는 다음 영상과 앱 재실행 후에도 유지됩니다.

**재생 → 자막 크기** 또는 제어판의 자막 버튼에서 작게·보통·크게 중 하나를 고를 수 있습니다. 선택한 크기는 앱을 다시 열어도 유지됩니다.

일반 재생과 PiP 재생 중에는 화면 보호기와 자동 잠자기를 막습니다. 일시 정지하거나 재생이 끝나면 원래 절전 설정이 적용됩니다.

Mac에 FaceTime이나 iPhone 연동 전화가 오면 재생 중인 영상이 일시 정지되고, 전화를 끊거나 거절하면 그 위치에서 이어집니다. 통화 대기 중에는 마지막 통화가 끝날 때까지 기다립니다. 이미 멈춰 둔 영상은 그대로 두며, 통화 중 직접 재생이나 일시 정지를 선택하거나 파일을 바꾸면 그 선택을 따릅니다.

| 입력 | 동작 |
| --- | --- |
| 영상 위에서 드래그 | 창 이동 |
| `1` / `2` / `3` | 영상 크기 50% / 100% / 200% (화면 안에 맞춤) |
| `Space` | 재생 / 일시 정지 |
| `←` / `→` | 10초 뒤로 / 앞으로 |
| `⌥←` / `⌥→` | 60초 뒤로 / 앞으로 |
| `⌘←` / `⌘→` | 이전 / 다음 영상 |
| `↑` / `↓` | 음량 5%p 조절 (앱을 다시 열어도 유지) |
| 트랙패드 위아래 스크롤 / 마우스 휠 | 트랙패드는 스크롤 거리에 비례해 음량 조절, 휠은 한 칸에 12.5%p 조절 |
| `M` | 음소거 / 직전 음량으로 복원 |
| `F` 또는 `Enter` | 전체 화면 전환 |
| `P` | 화면 속 화면(PiP) 전환 |
| `L` | 재생목록 열기 / 닫기 |
| `I` | 현재 작품 정보 |
| `Backspace` / `⌘Backspace` | 재생 중인 영상 파일 자체와 삭제 대상 외부 자막을 휴지통으로 보내지 않고 영구 삭제 (`Backspace`: 확인 후 / `⌘Backspace`: 확인 없이 즉시) |
