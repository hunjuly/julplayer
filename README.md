# JulPlayer

MKV, MOV, MP4, AVI 등을 지원하는 macOS용 동영상 플레이어입니다. Finder에서 영상을 열거나 플레이어에 끌어놓으면 해당 영상을 바로 재생하고 같은 폴더의 영상으로 재생목록을 갱신합니다. 재생이 끝나면 다음 파일로 넘어갑니다.

**파일 → 기본 플레이어로 연결 → 모든 동영상 형식 연결**을 선택하면 지원하는 확장자 전체를 한 번에 설정할 수 있습니다. 일부 형식은 macOS에서 확인을 요청할 수 있습니다.

## 빌드 및 실행

macOS 13 이상과 Xcode Command Line Tools가 필요합니다. 첫 빌드에서 재생 엔진인 libmpv를 자동으로 내려받습니다.

```sh
git clone https://github.com/hunjuly/julplayer.git
cd julplayer
./build.sh
open ./JulPlayer.app
```

## 주요 조작

오디오와 자막은 각각 직전에 사용한 트랙 순번을 기억합니다. 같은 순번이 없으면 1번으로 바뀌고 다음 영상도 1번부터 재생합니다. 재생 중에는 제목 막대와 제어판이 자동으로 숨고, 마우스를 움직이면 함께 나타납니다.

일반 재생과 PiP 재생 중에는 화면 보호기와 자동 잠자기를 막습니다. 일시 정지하거나 재생이 끝나면 원래 절전 설정이 적용됩니다.

| 입력 | 동작 |
| --- | --- |
| 영상 위에서 드래그 | 창 이동 |
| `1` / `2` / `3` | 영상 크기 50% / 100% / 200% (화면 안에 맞춤) |
| `Space` | 재생 / 일시 정지 |
| `←` / `→` | 10초 뒤로 / 앞으로 |
| `⌘←` / `⌘→` | 이전 / 다음 영상 |
| `↑` / `↓` 또는 트랙패드 위아래 스크롤 | 음량 조절 |
| `F` 또는 `Enter` | 전체 화면 전환 |
| `P` | 화면 속 화면(PiP) 전환 |
| `Backspace` / `⌘Backspace` | 현재 영상과 연결된 자막을 휴지통으로 이동 (확인 후 / 즉시) |
