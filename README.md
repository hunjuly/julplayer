# JulPlayer

MKV, MOV, MP4, AVI 등을 지원하는 macOS용 동영상 플레이어입니다. Finder에서 영상을 열거나 플레이어에 끌어놓으면 해당 영상을 바로 재생하고 같은 폴더의 영상으로 재생목록을 갱신합니다. 재생이 끝나면 다음 파일로 넘어갑니다.

**파일 → 기본 플레이어로 연결 → 모든 동영상 형식 연결**을 선택하면 지원하는 확장자 전체를 한 번에 설정할 수 있습니다. 일부 형식은 macOS에서 확인을 요청할 수 있습니다.

## 빌드 및 실행

macOS 13 이상과 Xcode Command Line Tools가 필요합니다. 첫 빌드에서 재생 엔진인 libmpv를 자동으로 내려받습니다.

```sh
git clone https://github.com/hunjuly/julplayer.git
cd julplayer
./build.sh
open ./JulPlayer.app
```

## 주요 조작

같은 폴더에 영상 이름과 일치하는 외부 자막이 있으면 그 자막을 기본으로 표시합니다. 자막 목록에서 내장 자막으로 바꿀 수 있고, 자막을 끄면 다음 영상에서도 꺼진 상태가 유지됩니다. 오디오와 자막은 직전에 사용한 트랙 순번을 기억하며 해당 순번이 없으면 1번으로 돌아갑니다.

영상 가운데의 반투명 버튼으로 재생·일시 정지와 앞뒤 10초·60초 이동을 조작합니다. 이전·다음 파일과 재생 위치는 하단 제어판에 있습니다. 창 폭이 가장 작으면 가운데 재생 버튼만 표시됩니다. 재생 중 마우스를 영상 위에 2초간 가만히 두면 버튼과 제목 막대, 제어판이 함께 숨고, 전체화면에서는 커서도 숨습니다. 창 안에서 마우스를 움직이면 다시 나타납니다.

파일이 바뀌면 현재 창의 가로폭을 유지하고 새 영상 비율에 맞춰 높이를 조절합니다.

HDR10·HLG 영상은 HDR이 활성화된 화면에서 HDR로 재생하고, 일반 화면에서는 밝기와 색을 SDR에 맞춰 자동으로 톤 매핑합니다. 창이나 PiP를 다른 화면으로 옮기면 해당 화면에 맞춰 전환합니다.

HDR 영상에서는 하단의 해 아이콘 옆에 현재 밝기 배율이 표시됩니다. **☀︎ ×1**을 누르면 슬라이더로 **×1**부터 **×10**까지 한 단계씩 조절할 수 있습니다. **재생 → 영상 밝기**에서도 같은 슬라이더를 열 수 있습니다. 기본값은 ×1이며, 선택한 밝기는 다음 영상과 앱 재실행 후에도 유지됩니다.

**재생 → 자막 크기** 또는 제어판의 자막 버튼에서 작게·보통·크게 중 하나를 고를 수 있습니다. 선택한 크기는 앱을 다시 열어도 유지됩니다.

일반 재생과 PiP 재생 중에는 화면 보호기와 자동 잠자기를 막습니다. 일시 정지하거나 재생이 끝나면 원래 절전 설정이 적용됩니다.

| 입력 | 동작 |
| --- | --- |
| 영상 위에서 드래그 | 창 이동 |
| `1` / `2` / `3` | 영상 크기 50% / 100% / 200% (화면 안에 맞춤) |
| `Space` | 재생 / 일시 정지 |
| `←` / `→` | 10초 뒤로 / 앞으로 |
| `⌥←` / `⌥→` | 60초 뒤로 / 앞으로 |
| `⌘←` / `⌘→` | 이전 / 다음 영상 |
| `↑` / `↓` | 음량 5%p 조절 (앱을 다시 열어도 유지) |
| 트랙패드 위아래 스크롤 / 마우스 휠 | 트랙패드는 스크롤 거리에 비례해 음량 조절, 휠은 한 칸에 10%p 조절 |
| `M` | 음소거 / 직전 음량으로 복원 |
| `F` 또는 `Enter` | 전체 화면 전환 |
| `P` | 화면 속 화면(PiP) 전환 |
| `L` | 재생목록 열기 / 닫기 |
| `Backspace` / `⌘Backspace` | 현재 영상과 연결된 자막 영구 삭제 (확인 후 / 즉시) |
